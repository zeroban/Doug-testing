Q: What are the required columns for importing volunteers?
A: 
- For New Volunteers:
  - First Name
  - Last Name
  - Email Address (must be unique for each volunteer)
- For Historical Hours:
  - First Name
  - Last Name
  - Email Address
  - Date Hours Occurred
  - Total Hours Worked

Q: How do I add historical hours for volunteers?
A: 
To add historical hours, you need to:
- Ensure the data is in the correct format (First Name, Last Name, Email Address, Date Hours Occurred, Total Hours Worked).
- If hours span multiple opportunities, run separate imports for each opportunity.

Q: How do I import new volunteers?
A: 
To import new volunteers, you need the following columns:
- First Name
- Last Name
- Email Address
